Rust · WASM ABI v1

1. Architecture & C ABI v1 Specification

PhotoCraft loads sandboxed WebAssembly filters compiled to the wasm32-unknown-unknown target. Plugins run in linear memory without operating system syscalls. Every filter exports four mandatory symbols:

  • pc_abi_version() -> i32: Returns integer 1.
  • pc_manifest() -> i64: Returns 64-bit packed pointer and length ((len << 32) | ptr) to a static JSON manifest string.
  • pc_alloc(size: i32) -> i32: Allocates memory inside the WebAssembly instance for input parameters and temporary buffers.
  • pc_filter(buf: i32, buf_len: i32, width: i32, height: i32, channels: i32, format: i32, params_ptr: i32, params_len: i32) -> i32: Applies the pixel transformation in-place. Returns 0 on success.

static MANIFEST: &[u8] = br#"{

  "name": "Duotone Tint & Luminance",
  "version": "0.1.0",
  "kind": "filter",
  "author": "Your Name",

  "area": "content"

#[cfg(target_arch = "wasm32")]
static mut HEAP_NEXT: usize = 65536;

#[no_mangle]
pub extern "C" fn pc_abi_version() -> i32 { 1 }

#[no_mangle]
pub extern "C" fn pc_manifest() -> i64 {
    ((MANIFEST.len() as i64) << 32) | (MANIFEST.as_ptr() as u32 as i64)
}

#[cfg(target_arch = "wasm32")]
#[no_mangle]
pub extern "C" fn pc_alloc(size: i32) -> i32 {
    if size <= 0 { return 0; }
    let size = size as usize;
    let start = unsafe { (HEAP_NEXT + 7) & !7usize };
    let end = match start.checked_add(size) { Some(v) => v, None => return 0 };
    let pages_needed = end.saturating_add(65535) / 65536;
    let pages_now = core::arch::wasm32::memory_size(0);
    if pages_needed > pages_now {
        let grown = core::arch::wasm32::memory_grow(0, pages_needed - pages_now);
        if grown == usize::MAX { return 0; }
    }
    unsafe { HEAP_NEXT = end; }
    start as i32
}

#[cfg(not(target_arch = "wasm32"))]
#[no_mangle]
pub extern "C" fn pc_alloc(_size: i32) -> i32 { 0 }

#[no_mangle]
pub unsafe extern "C" fn pc_filter(
    buf: i32, buf_len: i32, width: i32, height: i32, channels: i32,
    format: i32, _params_ptr: i32, _params_len: i32,
) -> i32 {
    if buf <= 0 || width <= 0 || height <= 0 || channels < 3 { return 1; }
    let count = (width as usize) * (height as usize) * (channels as usize);
    if count * 4 != (buf_len as usize) { return 2; }

    let pixels = slice::from_raw_parts_mut(buf as *mut f32, count);
    let ch = channels as usize;
    for pixel in pixels.chunks_exact_mut(ch) {
        let (r, g, b) = (pixel[0], pixel[1], pixel[2]);
        let lum = 0.2126 * r + 0.7152 * g + 0.0722 * b;
        // Warm sepia tint: high luminance preserves highlights, low warms shadows
        pixel[0] = (lum * 1.15).clamp(0.0, 1.0);
        pixel[1] = (lum * 0.95).clamp(0.0, 1.0);
        pixel[2] = (lum * 0.75).clamp(0.0, 1.0);
        // Alpha channel in pixel[3] remains untouched
    }
    0
}

WASM API v1 & ScriptUI / ExtendScript

Track A: Native Video Render Effect (WASM API v1)

Video rendering effects are sandboxed WebAssembly binaries operating on high-dynamic-range floating-point pixel buffers ([f32; 4] RGBA). They execute per-frame in the render pipeline with time and resolution awareness.

  • ec_api_version() -> i32: Returns 1.
  • ec_manifest_ptr() -> i32 & ec_manifest_len() -> i32: Returns pointer and byte length to the effect's JSON metadata.
  • ec_alloc(bytes: i32) -> i32: Allocates a reusable 8-byte aligned memory buffer for parameters and pixels.
  • ec_render(pixels, width, height, params, nparams, time, scale) -> i32: In-place frame render callback. time is seconds from comp start; scale is preview downsample multiplier (e.g. 1.0 = Full, 0.5 = Half).
EffectCraft WASM Effect (src/lib.rs) 
use std::cell::RefCell;

pub const MANIFEST: &str = r#"{
  "api": 1,
  "id": "org.effectcraft.plugins.chroma_pulse",
  "name": "Chroma Pulse",
  "category": "Color Correction",
  "version": "1.0.0",
  "author": "Community Developer",
  "description": "Procedural chromatic glow oscillating over composition time.",
  "params": [
    {"id": "intensity", "name": "Pulse Intensity", "type": "slider", "default": 50.0, "min": 0.0, "max": 100.0},
    {"id": "frequency", "name": "Pulse Speed (Hz)", "type": "slider", "default": 2.0, "min": 0.1, "max": 10.0}
  ]
}"#;

thread_local! {
    static BUF: RefCell<Vec<u64>> = const { RefCell::new(Vec::new()) };
}

#[no_mangle]
pub extern "C" fn ec_api_version() -> i32 { 1 }

#[no_mangle]
pub extern "C" fn ec_manifest_ptr() -> i32 { MANIFEST.as_ptr() as usize as i32 }

#[no_mangle]
pub extern "C" fn ec_manifest_len() -> i32 { MANIFEST.len() as i32 }

#[no_mangle]
pub extern "C" fn ec_alloc(bytes: i32) -> i32 {
    BUF.with(|b| {
        let mut b = b.borrow_mut();
        let words = (bytes.max(0) as usize).div_ceil(8);
        if b.len() < words { b.resize(words, 0); }
        b.as_mut_ptr() as usize as i32
    })
}

#[no_mangle]
pub unsafe extern "C" fn ec_render(
    pixels: i32, width: i32, height: i32,
    params: i32, nparams: i32, time: f64, _scale: f64,
) -> i32 {
    if width <= 0 || height <= 0 || nparams < 2 { return 1; }
    let p = std::slice::from_raw_parts(params as usize as *const f64, nparams as usize);
    let intensity = (p[0] / 100.0) as f32;
    let frequency = p[1] as f32;

    let pulse = 1.0 + intensity * ((time as f32 * frequency * 6.28318).sin() * 0.5);
    let total_pixels = (width as usize) * (height as usize);
    let px = std::slice::from_raw_parts_mut(pixels as usize as *mut [f32; 4], total_pixels);

    for pixel in px.iter_mut() {
        pixel[0] = (pixel[0] * pulse).min(1.0); // Red pulse
        pixel[1] = (pixel[1] * (2.0 - pulse)).min(1.0); // Inverse Green pulse
        // Blue and Alpha remain preserved
    }
    0
}

WASM ABI v1 & SVG Templates

1. Vector Object Filter Architecture (ABI v1)

VectorCraft object filters run as sandboxed WebAssembly modules that receive the active vector document as structured JSON, traverse paths, points, fills, and strokes, and return modified vector geometry.

  • vc_abi_version() -> u32: Returns 1.
  • vc_manifest() -> u64: Returns 64-bit packed slice (len << 32) | (ptr & 0xFFFFFFFF) of the JSON manifest.
  • vc_alloc(size: u32) -> u32: Memory allocator for passing input document buffers.
  • vc_run(input_ptr, input_len, params_ptr, params_len) -> i64: Deserializes the vector document, performs geometric or color transformations, and returns a packed pointer/length to the serialized output JSON.
VectorCraft Object Filter (src/lib.rs) 
use serde_json::{Value, json};

const MANIFEST: &str = r#"{
  "id": "org.vectorcraft.community.scale_stroke",
  "name": "Proportional Stroke Scaler",
  "version": "1.0.0",
  "kind": "filter",
  "author": "Community Developer",
  "description": "Scales stroke weights proportionally across all nested path hierarchies.",
  "params": {
    "scale_factor": {"type": "number", "min": 10, "max": 500, "default": 150}
  }
}"#;

#[no_mangle]
pub extern "C" fn vc_abi_version() -> u32 { 1 }

fn pack(slice: &[u8]) -> u64 {
    let ptr = slice.as_ptr() as usize as u64;
    let len = slice.len() as u64;
    (len << 32) | (ptr & 0xFFFF_FFFF)
}

#[no_mangle]
pub extern "C" fn vc_manifest() -> u64 { pack(MANIFEST.as_bytes()) }

#[no_mangle]
pub extern "C" fn vc_alloc(size: u32) -> u32 {
    let mut block = Vec::<u8>::with_capacity(size as usize);
    let ptr = block.as_mut_ptr();
    std::mem::forget(block);
    ptr as usize as u32
}

fn scale_strokes(obj: &mut Value, factor: f64) {
    if let Value::Object(map) = obj {
        if let Some(stroke) = map.get_mut("stroke") {
            if let Some(w) = stroke.get_mut("width") {
                if let Some(num) = w.as_f64() {
                    *w = json!(num * factor);
                }
            }
        }
        if let Some(Value::Array(children)) = map.get_mut("children") {
            for child in children {
                scale_strokes(child, factor);
            }
        }
    }
}

#[no_mangle]
pub unsafe extern "C" fn vc_run(input: *const u8, input_len: u32, params: *const u8, params_len: u32) -> i64 {
    let in_slice = std::slice::from_raw_parts(input, input_len as usize);
    let param_slice = std::slice::from_raw_parts(params, params_len as usize);

    let mut doc: Value = match serde_json::from_slice(in_slice) {
        Ok(v) => v,
        Err(_) => return -1,
    };
    let params_val: Value = serde_json::from_slice(param_slice).unwrap_or(Value::Null);
    let factor = params_val.get("scale_factor").and_then(Value::as_f64).unwrap_or(150.0) / 100.0;

    if let Some(objects) = doc.get_mut("objects").and_then(Value::as_array_mut) {
        for obj in objects {
            scale_strokes(obj, factor);
        }
    }

    let out_bytes = match serde_json::to_vec(&doc) {
        Ok(b) => b,
        Err(_) => return -2,
    };
    pack(out_bytes.leak()) as i64
}

2. Procedural 3D LUT Generator (.cube)

Use Python to mathematically generate matching 17x17x17 or 33x33x33 3D Look-Up Tables with gamma curves and color grading matrices:

generate_lut.py 
#!/usr/bin/env python3
"""Generate a calibrated 17-point 3D LUT in Adobe/DaVinci .cube format."""
SIZE = 17

def grade(r, g, b):
    # Luminance calculation
    lum = 0.2126 * r + 0.7152 * g + 0.0722 * b
    # Apply warm highlights and cool shadows
    r_out = (r - 0.5) * 1.1 + 0.5 + 0.04 * lum
    g_out = (g - 0.5) * 1.1 + 0.5
    b_out = (b - 0.5) * 1.1 + 0.5 - 0.03 * lum
    return tuple(max(0.0, min(1.0, c)) for c in (r_out, g_out, b_out))

with open("Teal_Orange.cube", "w", encoding="utf-8") as f:
    f.write('TITLE "Teal & Orange"\n')
    f.write(f'LUT_3D_SIZE {SIZE}\n')
    f.write('DOMAIN_MIN 0.0 0.0 0.0\nDOMAIN_MAX 1.0 1.0 1.0\n')
    n = SIZE - 1
    for b in range(SIZE):
        for g in range(SIZE):
            for r in range(SIZE):
                rg, gg, bg = grade(r / n, g / n, b / n)
                f.write(f"{rg:.6f} {gg:.6f} {bg:.6f}\n")
print("Generated Teal_Orange.cube")

Real-Time Audio DSP Callback (Rust / nih-plug pattern) 
// Simple Stereo Gain & Soft Saturation DSP Kernel
pub struct SimpleSaturator {
    pub drive_db: f32,
    pub output_gain_db: f32,
}

impl SimpleSaturator {
    pub fn process_block(&mut self, channels: &mut [&mut [f32]], num_samples: usize) {
        let drive = 10.0f32.powf(self.drive_db / 20.0);
        let out_gain = 10.0f32.powf(self.output_gain_db / 20.0);

        for ch in channels.iter_mut() {
            for sample in ch[..num_samples].iter_mut() {
                let x = *sample * drive;
                // Soft cubic tanh saturation curve: f(x) = x - (x^3)/3
                let saturated = if x > 1.0 { 0.6667 } else if x < -1.0 { -0.6667 } else { x - (x * x * x) / 3.0 };
                *sample = saturated * out_gain;
            }
        }
    }
}

        var qtyField = this.getField("Qty." + i);
        var priceField = this.getField("Price." + i);
        var lineField = this.getField("Total." + i);
        if (qtyField && priceField && lineField) {
            var qty = Number(qtyField.value) || 0;
            var price = Number(priceField.value) || 0;
            var lineTotal = qty * price;
            lineField.value = lineTotal;
            subtotal += lineTotal;
        }
    }
    // Set Subtotal, Tax (8.5%), and Grand Total
    var subtotalField = this.getField("Subtotal");
    if (subtotalField) subtotalField.value = subtotal;

    var taxRate = 0.085;
    var tax = subtotal * taxRate;
    var taxField = this.getField("Tax");
    if (taxField) taxField.value = tax;

    var grandTotalField = this.getField("GrandTotal");
    if (grandTotalField) grandTotalField.value = subtotal + tax;
}

// Keystroke Validator: Restrict to positive numeric entries
function validateNumericKeystroke(event) {
    if (event.willCommit) {
        var n = Number(event.value);
        if (isNaN(n) || n < 0) {
            if (typeof app !== "undefined" && app.alert) {
                app.alert("Invalid input: Please enter a positive number.");
            }
            event.rc = false; // Reject commit
        }
    }
}

CONTRIBUTING & PUBLISHING

Publishing Extensions to the ArtCraft Store

Follow this 5-step checklist to register a new plugin, filter, tool, preset, or template package in the official ArtCraft Store catalog.

Step 1: Declare Extension in catalog.json

Add a unique entry adhering to the ArtCraft Store schema v2. Ensure your extension ID follows the reverse-DNS format org.<app>.<author>.<slug>:

{
  "id": "org.effectcraft.community.myplugin",
  "name": "My Plugin Name",
  "version": "1.0.0",
  "author": "Your Name / Organization",
  "description": "Clear 1-sentence summary of what your extension accomplishes.",
  "kind": "tool",
  "abi": 1,
  "source": "plugins/myplugin",
  "sourceUrl": "https://github.com/akkk09/artcraft-store/tree/main/plugins/myplugin",
  "artifact": "MyPlugin.jsx",
  "releaseAsset": "MyPlugin.jsx",
  "tags": ["animation", "workflow", "automation"],
  "app": "effectcraft",
  "compatibility": "EffectCraft ScriptUI / ExtendScript"
}

Step 2: Add Build & Staging Target in build-all.sh

Register your compilation or asset copy command in build-all.sh to stage outputs in dist/:

# For Rust / WASM filters:
cargo build --manifest-path "plugins/myplugin/Cargo.toml" --release --target wasm32-unknown-unknown
cp plugins/myplugin/target/wasm32-unknown-unknown/release/myplugin.wasm dist/

# For ExtendScript / ScriptUI panels:
cp plugins/myplugin/MyPlugin.jsx dist/

# For ZIP template / preset archives:
python plugins/myplugin/package.py --output dist/myplugin-toolkit.zip

Step 3: Register CI Test & Release Steps

In .github/workflows/build-plugins.yml, add automated testing for your algorithm and declare your release asset:

# Under test steps:
- name: Test My Plugin algorithms
  run: cargo test --manifest-path plugins/myplugin/Cargo.toml

# Under release assets:
  files: |
    dist/MyPlugin.wasm
    dist/MyPlugin.jsx

Step 4: Local Audit & Verification Pre-flight

Verify that your catalog entry is syntactically valid and that all declared artifacts exist in dist/ before pushing:

# 1. Run full catalog & artifact verification
python3 scripts/validate_catalog.py --check-artifacts

# 2. Run unit test suite
python3 -m unittest discover tests

# 3. Test plugin implementation
cargo test --manifest-path plugins/myplugin/Cargo.toml
