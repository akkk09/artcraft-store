Part 01 / User Guide

Installing Extensions by App

Each ArtCraft application uses an extensible architecture suited to its domain. Follow the instructions below for your specific application and operating system.

Select Your Operating System:
P

PhotoCraft

WASM Filters (ABI v1) & 3D LUTs

PhotoCraft executes WebAssembly pixel-manipulation modules (compiled to wasm32-unknown-unknown) in a secure memory-isolated sandbox, as well as 3D color cubes (.cube).

OSPlugin Directory (`.wasm`)Action
Linux ~/.config/photocraft/plugins/
macOS ~/Library/Application Support/PhotoCraft/Plugins/
Windows %APPDATA%\PhotoCraft\Plugins\

How to Activate:

  1. Download the .wasm binary (e.g. photocraft_plugin_smudge.wasm or vignette.wasm).
  2. Copy the file into your platform's plugins/ directory listed above.
  3. Launch PhotoCraft (or click Filters ▸ Rescan Plug-in Directory).
  4. Access your filter from the top Filter menu under its registered category.
  5. For 3D LUTs: Open Image ▸ Adjustments ▸ Apply 3D LUT... and select your .cube file, or use our browser-based LUT Studio to tune and export preview frames.
E

EffectCraft

WASM Render Plugins (API v1) & ScriptUI Panels (.jsx)

EffectCraft supports two distinct extension categories: high-performance render plugins (compiled WASM / WAT) that operate on video buffers, and dockable ScriptUI / ExtendScript UI panels (.jsx) for timeline manipulation and keyframing.

TypePlatform DirectoryAction
Linux WASM ~/.config/effectcraft/plugins/
Linux ScriptUI ~/.config/effectcraft/Scripts/ScriptUI Panels/
macOS WASM ~/Library/Application Support/EffectCraft/Plug-ins/
macOS ScriptUI ~/Library/Application Support/EffectCraft/Scripts/ScriptUI Panels/
Windows WASM %APPDATA%\EffectCraft\Plug-ins\
Windows ScriptUI %APPDATA%\EffectCraft\Scripts\ScriptUI Panels\

Loading EffectCraft Extensions:

  • WASM/WAT Render Plugins (e.g. DepthCraft, Chromatic Fringe): Place in the plugins folder or load on-the-fly via Effect ▸ Load Effect Plug-in.... The effect will appear in the Effect Controls inspector.
  • ScriptUI Panels (e.g. EaseCraft, CaptionCraft, QuietCraft): Place the .jsx script inside the Scripts/ScriptUI Panels/ folder and restart EffectCraft. The tool is available directly in the Window menu (e.g. Window ▸ QuietCraft.jsx) and can be docked anywhere in your workspace.
V

VectorCraft

WASM Object Filters (ABI v1) & SVG Template Packages

VectorCraft provides procedural path transforms and color appearance filters running in a fuel-metered wasmi engine, preventing infinite loops while manipulating complex Bézier geometries.

OSPlugin Path (`.wasm`)Template Path (`.zip` / `.svg`)
Linux ~/.config/vectorcraft/plugins/ ~/.config/vectorcraft/templates/
macOS ~/Library/Application Support/VectorCraft/Plugins/ ~/Library/Application Support/VectorCraft/Templates/
Windows %APPDATA%\VectorCraft\Plugins\ %APPDATA%\VectorCraft\Templates\

Activation:

For WASM object filters (e.g. vectorcraft_plugin_recolor.wasm), open Window ▸ Plug-in Manager or select artwork and click Object ▸ Live Filters ▸ Recolor & Tone. For template packs (e.g. Creator Graphics Pack), extract the SVG files into your templates folder and select File ▸ New From Template....

F

FilmCraft

Native Timeline Effect Presets (JSON v1) & 3D LUTs

FilmCraft supports declarative effect stacks serialized as structured JSON (format filmcraft.effect-presets v1) combining color grading, grain, and motion transforms, alongside industry-standard 17/33/65 .cube files.

Installing Presets & LUTs:

  • GUI Import: In FilmCraft's Effects Panel, right-click the Presets bin and choose Import Presets..., then select your downloaded .json or extracted preset package.
  • CLI Batch Import: Launch FilmCraft headlessly or via automation: 
    filmcraft-cli --project project.fcproj exec presets.import '{"path":"./film-emulation-presets.json"}'
  • Creative LUTs: Save .cube files to ~/.config/filmcraft/LUTs/Creative/ (Linux) or ~/Library/Application Support/FilmCraft/LUTs/Creative/ (macOS) to appear automatically in the Lumetri Look dropdown.
S

SoundCraft

CLAP (.clap), VST3 (.vst3), Audio Units (.component) & Channel Presets

SoundCraft acts as a modern, host-compliant DAW and mixing environment. It loads open CLAP plugins, VST3 bundles, macOS Audio Units, and custom DSP channel strip presets without wrapping or bridges.

FormatStandard Platform LocationsAction
CLAP (Linux) ~/.clap/ or /usr/lib/clap/
VST3 (Linux) ~/.vst3/ or /usr/lib/vst3/
CLAP (macOS) ~/Library/Audio/Plug-Ins/CLAP/
VST3 (macOS) ~/Library/Audio/Plug-Ins/VST3/
AU (macOS) ~/Library/Audio/Plug-Ins/Components/
CLAP (Win) %COMMONPROGRAMFILES%\CLAP\
VST3 (Win) %COMMONPROGRAMFILES%\VST3\

Scanning and Loading:

In SoundCraft, go to Preferences ▸ Audio Plug-ins ▸ Rescan All. To load a channel strip preset package (e.g. SoundCraft Audio Toolkit), click the header menu on any mixer track insert rack and choose Load Channel Strip Preset....

A

PdfCraft

Acrobat JavaScript (ISO 32000 in Boa Sandbox)

PdfCraft executes form calculations, field validation, and document automation scripts using an embedded, memory-safe Boa JavaScript engine conforming to ISO 32000-1 specifications.

Adding Scripts to PDF Documents:

  • Field Calculations (e.g. Invoice Calculator): Open your PDF in PdfCraft, switch to Form Edit Mode, select the target field (e.g. TotalAmount), click Properties ▸ Calculate ▸ Custom Calculation Script, and paste the code from pdfcraft-invoice-calculator.js.
  • Document-Level JavaScripts: Go to Tools ▸ JavaScript ▸ Document JavaScripts, enter a script name, and click Add / Edit to register global helper functions that run when the document opens.
D

DesignCraft

IDML Publication Templates & Typographic Styles

DesignCraft accepts InDesign Markup Language (.idml) templates, paragraph style catalogs, and master spread presets. Place downloaded template archives in Documents/DesignCraft/Templates/ and open via File ▸ New From Template....

L

LightCraft

RAW Develop Presets & 3D LUT Profiles

Import non-destructive develop presets into LightCraft by opening the Develop module, expanding the Presets sidebar, and clicking (+) ▸ Import Presets.... 3D LUT profiles (.cube) can be loaded directly from the Color Grading ▸ Profile panel.

C

CADCraft

Command Automation Scripts & Parametric DXF Macros

CADCraft executes command scripts (.cadscr) and geometric drawing macros. In the CADCraft command line prompt at the bottom of the workspace, type SCRIPT "path/to/script.cadscr", or load macros via Tools ▸ Run Macro / Script....

Part 02 / Technical Reference

Extension Architectures & Sandboxing

ArtCraft applications are designed around strict security boundaries, low latency, and zero dependency friction. Here is how each architecture functions under the hood:

Host Application Extension Architecture Sandbox / Runtime File Types Isolation & Permissions
PhotoCraft WebAssembly ABI v1 Wasmtime (Linear Memory) .wasm, .cube No FS/Network. Pure pixel buffers.
EffectCraft WASM API v1 + ScriptUI Wasmtime + ExtendScript Engine .wasm, .wat, .jsx Render sandboxed; UI scoped to Host DOM.
VectorCraft Object Filter ABI v1 wasmi (Fuel-metered) .wasm, .svg Path transform buffer. Gas-limited.
FilmCraft Native Preset Graphs Native JSON Deserializer .json, .cube Pure declarative state. Zero exec code.
SoundCraft CLAP / VST3 / AU Host Native Process DSP Threads .clap, .vst3, .component Realtime priority, buffer audio processing.
PdfCraft Acrobat JS (ISO 32000) Boa JavaScript Engine (Rust) .js Restricted to document field DOM.
DesignCraft Publication Templates IDML XML Parser .idml, .zip Declarative layout structures.
LightCraft Develop Profiles Color Pipe Engine .xmp, .cube Parameter curves & 3D LUT matrices.
CADCraft Automation Scripts Command Interpreter .cadscr, .py Headless drawing command dispatch.
💡
Why WebAssembly ABI v1?

By compiling to WebAssembly without OS system calls (wasm32-unknown-unknown), plugins run identically across Linux, macOS, and Windows with near-native speed, zero installation dependencies, and complete protection against unauthorized filesystem or network access.

Part 03 / SDK Reference

Developer Guide: Building a Plugin

Creating an ArtCraft plugin takes only a few minutes. Whether you are writing a WebAssembly image filter in Rust or an ExtendScript animation tool in JavaScript, here is the recommended developer setup.

1. Building a PhotoCraft or VectorCraft WASM Plugin in Rust

Install the Rust toolchain and add the WebAssembly target:

rustup target add wasm32-unknown-unknown

Configure your Cargo.toml as a cdylib:

[package]
name = "my-photocraft-filter"
version = "1.0.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]

[dependencies]

In src/lib.rs, export the standard ABI v1 memory allocation and processing symbols:

#[no_mangle]
pub extern "C" fn allocate(size: usize) -> *mut u8 {
    let mut buf = Vec::with_capacity(size);
    let ptr = buf.as_mut_ptr();
    std::mem::forget(buf);
    ptr
}

#[no_mangle]
pub extern "C" fn deallocate(ptr: *mut u8, size: usize) {
    unsafe { drop(Vec::from_raw_parts(ptr, 0, size)); }
}

#[no_mangle]
pub extern "C" fn process_frame(ptr: *mut u8, width: u32, height: u32, param: f32) {
    let len = (width * height * 4) as usize;
    let pixels = unsafe { std::slice::from_raw_parts_mut(ptr, len) };
    // Process RGBA pixel buffer in-place...
}

Compile to optimized WebAssembly:

cargo build --target wasm32-unknown-unknown --release

2. Building an EffectCraft ScriptUI Panel (.jsx)

ScriptUI panels are dockable JavaScript scripts using the host ExtendScript environment. Here is a clean boilerplate:

(function(thisObj) {
  var win = (thisObj instanceof Panel) ? thisObj : new Window('palette', 'MyTool', undefined, {resizeable: true});
  win.orientation = 'column';
  win.alignChildren = ['fill', 'top'];

  var btn = win.add('button', undefined, 'Apply Effect');
  btn.onClick = function() {
    app.beginUndoGroup('Apply Tool Action');
    // Timeline and layer manipulation code...
    app.endUndoGroup();
  };

  win.layout.layout(true);
  if (win instanceof Window) win.show();
})(this);
Part 04 / Store Catalog

Submitting an Item to the Store

The ArtCraft Store is 100% open-source and catalog-driven. To add your extension to the website and Launcher API, submit a pull request with an entry in catalog.json.

Catalog Entry Schema

Add a new JSON object to the plugins array in catalog.json:

{
  "id": "org.example.my-filter",
  "app": "photocraft",
  "name": "My Amazing Filter",
  "version": "1.0.0",
  "author": "Your Name or Handle",
  "license": "MIT",
  "kind": "filter",
  "description": "Clear, concise summary of what this tool accomplishes.",
  "tags": ["creative", "procedural", "retouch"],
  "compatibility": "ABI v1",
  "sourceUrl": "https://github.com/yourname/my-filter",
  "downloadUrl": "https://github.com/yourname/my-filter/releases/download/v1.0.0/my_filter.wasm",
  "releaseAsset": "my_filter.wasm"
}

Validation Checklist & Commands

Before submitting your PR, run the local validation suite to ensure your metadata complies with all schema rules:

python3 -m unittest tests/test_catalog.py
python3 scripts/validate_catalog.py --check-artifacts
✅
Submission Criteria:

1. Target app must be one of the 9 supported IDs.
2. id must use reverse-DNS notation (e.g. org.author.plugin) and be globally unique.
3. The plugin must be licensed under an open-source or permissive license (e.g. MIT, Apache 2.0, BSD).
4. If including local source in plugins/, add compilation steps to build-all.sh.

Part 05 / Support

Troubleshooting & Frequently Asked Questions

Why isn't my WASM plugin showing up in PhotoCraft or EffectCraft?

Check the following common causes:

  1. Target Directory: Ensure the file is placed directly in the app's plugins/ folder, not in an unextracted ZIP or subfolder.
  2. Rescan: Use Filters ▸ Rescan Plug-in Directory in PhotoCraft, or completely restart the host application.
  3. Architecture Mismatch: The WebAssembly binary must target wasm32-unknown-unknown. If compiled for wasm32-wasi, the host may reject symbols expecting WASI system calls.
How do I resolve macOS Gatekeeper / Quarantine warnings on downloaded plugins?

When downloading plug-ins (such as .clap or .vst3) via a web browser, macOS may mark the file with a quarantine attribute. You can remove it via Terminal:

xattr -d com.apple.quarantine ~/Library/Audio/Plug-Ins/CLAP/plugin.clap
My ScriptUI panel (.jsx) does not show up in EffectCraft's Window menu.

Make sure the script is placed inside Scripts/ScriptUI Panels/ (the exact subfolder name matters). Files placed in the root Scripts/ folder only appear under File ▸ Scripts ▸ Run Script, whereas panels placed in ScriptUI Panels/ are dockable and register automatically under the Window menu upon application startup.

Can I use external crates / dependencies in my WebAssembly plugins?

Yes! Any Rust crate that supports no_std or does not invoke operating system syscalls (like thread spawning, filesystem I/O, or raw networking) will compile cleanly and run inside the ArtCraft sandbox. Fast math, color science, easing algorithms, and image processing libraries work out-of-the-box.

How does the Launcher API work for custom tools?

The ArtCraft Store provides a public, static, zero-configuration JSON API. Launchers and package managers can consume catalog.json and api/v1/manifest.json or import the JavaScript client at api/v1/client.js without requiring API keys or user authentication.
