Step-by-step setup guides, directory paths, and developer architecture references for all ArtCraft creative applications.

P

PhotoCraft

WASM Filters (ABI v1) & 3D LUTs

Executes sandboxed WebAssembly pixel-manipulation modules (compiled to wasm32-unknown-unknown) with zero OS syscalls, alongside 3D color cubes (.cube).

Linux: ~/.config/photocraft/plugins/
macOS: ~/Library/Application Support/PhotoCraft/Plugins/
Windows: %APPDATA%\PhotoCraft\Plugins\
  1. Download the .wasm filter binary (or .cube 3D LUT file).
  2. Copy the file into your platform's plugins directory listed above.
  3. Launch PhotoCraft or select Filter ▸ Rescan Plug-in Directory.
  4. Access the filter under the Filter menu in its registered category.
  5. For 3D LUTs: Apply via Image ▸ Adjustments ▸ Apply 3D LUT... or use LUT Studio.
E

EffectCraft

WASM Render Filters (API v1) & ScriptUI Panels (.jsx)

High-performance video render filters in WASM/WAT, paired with dockable ExtendScript panels for keyframing, captions, and audio silence removal.

Linux: WASM: ~/.config/effectcraft/plugins/ | ScriptUI: ~/.config/effectcraft/Scripts/ScriptUI Panels/
macOS: WASM: ~/Library/Application Support/EffectCraft/Plug-ins/ | ScriptUI: Scripts/ScriptUI Panels/
Windows: WASM: %APPDATA%\EffectCraft\Plug-ins\ | ScriptUI: Scripts\ScriptUI Panels\
  1. Render Plugins (.wasm, .wat): Place in plugins folder or load via Effect ▸ Load Effect Plug-in....
  2. ScriptUI Panels (.jsx like PivotCraft, QuietCraft, EaseCraft): Copy into Scripts/ScriptUI Panels/ and restart EffectCraft.
  3. Open your panel from the Window menu (e.g. Window ▸ QuietCraft.jsx).
  4. Dock the panel anywhere in your workspace alongside Effect Controls and Timeline.
V

VectorCraft

Object Filters (ABI v1) & SVG Templates (.zip)

Procedural path transforms running in a gas-limited wasmi sandbox, plus editable SVG template packages.

Linux: Plugins: ~/.config/vectorcraft/plugins/ | Templates: ~/.config/vectorcraft/templates/
macOS: Plugins: ~/Library/Application Support/VectorCraft/Plugins/ | Templates: Templates/
Windows: Plugins: %APPDATA%\VectorCraft\Plugins\ | Templates: Templates\
  1. WASM Filters: Copy to plugins folder; open Window ▸ Plug-in Manager or Object ▸ Live Filters.
  2. SVG Templates: Extract archive into templates directory and select File ▸ New From Template....
F

FilmCraft

Timeline Effect Presets (JSON v1) & 3D LUTs (.cube)

Declarative parameter and effect chains (filmcraft.effect-presets v1) and 17/33/65-point 3D Look-Up Tables.

Linux: LUTs: ~/.config/filmcraft/LUTs/Creative/
macOS: LUTs: ~/Library/Application Support/FilmCraft/LUTs/Creative/
Windows: LUTs: %APPDATA%\FilmCraft\LUTs\Creative\
  1. GUI Import: Right-click Effects panel Presets bin ▸ Import Presets... and select the JSON file.
  2. CLI Import: Run filmcraft-cli --project project.fcproj exec presets.import '{"path":"presets.json"}'.
  3. Creative LUTs: Save .cube files to your LUTs folder or select Lumetri Color ▸ Creative ▸ Look LUT.
S

SoundCraft

CLAP (.clap), VST3 (.vst3), Audio Units & DSP Presets

Host-compliant digital audio workstation loading open CLAP, VST3, and macOS Audio Units with sample-accurate automation.

Linux: CLAP: ~/.clap/ or /usr/lib/clap/ | VST3: ~/.vst3/ or /usr/lib/vst3/
macOS: CLAP: ~/Library/Audio/Plug-Ins/CLAP/ | VST3: Plug-Ins/VST3/ | AU: Components/
Windows: CLAP: %COMMONPROGRAMFILES%\CLAP\ | VST3: %COMMONPROGRAMFILES%\VST3\
  1. Place third-party audio plugins in your platform's standard audio plugin directory.
  2. In SoundCraft, open Preferences ▸ Audio Plug-ins ▸ Rescan All.
  3. Insert the plugin on any channel strip track.
  4. Channel Strip Presets: Load via the track insert header menu (Load Channel Strip Preset...).
A

PdfCraft

Acrobat JavaScript (ISO 32000 in Boa Sandbox)

Interactive forms, field calculations, and automation scripts running in a sandboxed pure-Rust JavaScript engine.

Target: Tools ▸ JavaScript ▸ Document JavaScripts
  1. Form Calculations: Open PDF in PdfCraft, switch to Form Edit Mode.
  2. Right-click field ▸ Properties ▸ Calculate ▸ Custom Script and paste calculation logic (e.g. from pdfcraft-invoice-calculator.js).
  3. Document Scripts: Register global scripts via Tools ▸ JavaScript ▸ Document JavaScripts.
D

DesignCraft

IDML Publication Templates & Typographic Styles

Multi-page layout templates, master spreads, and typography style packages.

Path: Documents/DesignCraft/Templates/
  1. Save downloaded template archives to Documents/DesignCraft/Templates/.
  2. Open directly with File ▸ New From Template... or File ▸ Open....
  3. Load paragraph & character styles from the Paragraph Styles panel flyout menu.
L

LightCraft

RAW Develop Presets (.xmp) & 3D LUT Profiles (.cube)

Non-destructive RAW photo development parameter curves and color grading profiles.

Linux: ~/.config/lightcraft/presets/
macOS: ~/Library/Application Support/LightCraft/Presets/
Windows: %APPDATA%\LightCraft\Presets\
  1. Open LightCraft's Develop module.
  2. Click Presets panel (+) ▸ Import Presets... and select .xmp or preset bundle.
  3. Load 3D LUT profiles in Color Grading ▸ Profiles dropdown.
C

CADCraft

Command Scripts (.cadscr) & Geometric Macros

Parametric drafting automation, batch coordinate drawing, and procedural geometry macros.

Linux: ~/.config/cadcraft/scripts/
macOS: ~/Library/Application Support/CADCraft/Scripts/
Windows: %APPDATA%\CADCraft\Scripts\
  1. In CADCraft command line prompt, run: SCRIPT "path/to/script.cadscr".
  2. Run interactive macros via Tools ▸ Run Macro / Script....
  3. Bind macros to workspace shortcut keys or custom toolbar buttons.
COMMUNITY FORKS & EXTENDED RUNTIMES

Modified Application Builds & Custom Plugin Runtimes

Unlike standard plug-ins, community forks directly modify the underlying ArtCraft application repositories to introduce custom engine runtimes, external plugin hosting standards (such as OpenFX), or third-party project interchange.

E

EffectCraft (OpenFX & .aep Import)

by glumbis · Unofficial Fork of EffectCraft (C++20 / Qt)
Latest Release (v0.7.0-ofx.2) ↗ Source Repo ↗

An experimental community fork of EffectCraft adding native OpenFX (OFX) plug-in hosting support (Boris FX Sapphire, RE:Vision Effects RSMB & Twixtor) and Adobe After Effects project (.aep, .aepx) import via py-aep.

OpenFX Path: C:\Program Files\Common Files\OFX\Plugins\
  1. Download the standalone release archive from glumbis/effectcraft releases (e.g. EffectCraft-OFX-windows.zip).
  2. Extract and run the custom effectcraft.exe executable (portable build, does not overwrite upstream install).
  3. Installed OpenFX bundles in C:\Program Files\Common Files\OFX\Plugins\ appear in the Effects panel under their respective vendor categories.
  4. Import After Effects compositions via File ▸ Import ▸ After Effects Project (.aep)....

Developer & SDK Architecture

Build native WebAssembly filters in Rust using wasm32-unknown-unknown:

cargo build --target wasm32-unknown-unknown --release

Run the local store catalog audit and unit test suite:

python3 -m unittest tests/test_catalog.py
python3 scripts/validate_catalog.py --check-artifacts
