# Creator Graphics Pack

A cohesive starter set of editable SVG templates for video creators and small channels.

| File | Canvas | Use |
|---|---:|---|
| video-thumbnail.svg | 1280 × 720 | Video thumbnail |
| channel-banner.svg | 2560 × 1440 | Channel banner; includes a safe-area guide |
| end-screen.svg | 1920 × 1080 | Two video slots and subscribe mark |
| lower-third.svg | 1920 × 1080 | Transparent name/role overlay |
| social-post.svg | 1080 × 1080 | Square announcement post |
| creator-avatar.svg | 800 × 800 | Abstract creator profile mark |

Open in VectorCraft or another SVG-compatible vector editor. Replace the sample copy and initials, then adjust the shapes and colors. Text appearance depends on fonts installed locally. Hide or delete the banner's dashed guide before export. The lower-third background is transparent. No remote assets, stock imagery, or third-party logos are included.
