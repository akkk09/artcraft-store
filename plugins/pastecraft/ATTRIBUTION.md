# PasteCraft Attribution and Licensing

PasteCraft is an original universal clipboard asset importer, vector converter, and layer replacer tool created for EffectCraft.

## Original Clean-Room Implementation
- Developed independently from scratch for the EffectCraft ecosystem.
- Designed as a clean-room workflow utility inspired by standard clipboard asset importing practices (reference concept: JustPaste by Saber Naeemi on aescripts + aeplugins).
- All Rust algorithms, MIME classification, base64 decoding, destructive change preview contracts, and ScriptUI panel code are original implementations.
