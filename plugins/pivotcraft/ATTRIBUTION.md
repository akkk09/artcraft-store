# PivotCraft Attribution and Licensing

PivotCraft is an original anchor-point placement, layer alignment, and transform compensation tool for EffectCraft.

## Clean-Room Implementation
- **Original Code**: All ExtendScript (ScriptUI) and Rust code is original work created specifically for EffectCraft.
- **Reference**: Clean-room implementation based solely on public product descriptions (e.g. Anchor Pro on aescripts.com) and EffectCraft's public scripting and engine APIs.
- **Licensing**: Dual-licensed under MIT OR Apache-2.0, matching EffectCraft's open-source licensing.
- **No Proprietary Dependencies**: No proprietary code, closed-source presets, or copyrighted artwork are included.
