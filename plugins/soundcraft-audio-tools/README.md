# SoundCraft Audio Toolkit

Channel strip presets, DSP configurations, and plugin integration guides for SoundCraft.

## Features
- **Channel Strip Presets**: Broadcast Voice Strip, Podcast Master Limiter, and Acoustic Warmth.
- **CLAP & VST3 Integration**: Guides and preset mappings for third-party CLAP (`.clap`), VST3 (`.vst3`), and AU (`.component`) plugins.
- **Zero-Dependency Presets**: Compatible with SoundCraft mix automation.

## Installation
Extract `soundcraft-audio-toolkit.zip` and import presets in SoundCraft via **Mixer ▸ Channel Strip ▸ Load Preset**.
