# Creator Graphics Pack

A static SVG template pack, not an executable plug-in. The original source templates are in `assets/creator-graphics-pack/`.

Build the distributable archive from the repository root:

```sh
python plugins/creator-graphics-pack/package.py --output dist/creator-graphics-pack.zip
```

Open the SVGs in VectorCraft or another SVG-compatible vector editor. Customize the example copy, shapes, and colors before use. The included artwork is dedicated to the public domain under CC0 1.0.
