# Vector Recolor & Tone

Object filter plug-in for VectorCraft (VectorCraft ABI v1).

## Features
- Procedural saturation, brightness, and luminance adjustment across selected vector paths and shapes.
- Modifies fill and stroke colors in-place while preserving geometry, layers, and opacity.
- Sandboxed WebAssembly implementation.

## Installation
In VectorCraft, open the Plugin Manager and load `vectorcraft_plugin_recolor.wasm`.
