Know what you're installing

This store currently lists ABI v1 whole-image filters. They are not interactive drag-to-paint brushes. Review the source and compatibility notes before using a plugin.

Pick a plugin

Search the catalog, check its type, version, and source repository.

02 / DOWNLOAD

Get the WASM file

Download the WASM file from the plug-in listing.

03 / INSTALL

Load in PhotoCraft

Open PhotoCraft and use its plug-in installation option, if supported by your build. Select the downloaded .wasm file.
